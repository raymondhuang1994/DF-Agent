# TeamAdvisor 0.3.0 验证报告

验收日期：2026-11-16。当前 Windows 客户端应用版本 26.1106.51428、构建 26605。0.3.0 在 0.2.0 已验证的专业技能路由与合成集成上新增本机配置、明确反馈及个人/项目记忆。

## 本版已完成

| 验证 | 实际结果 |
|---|---|
| 回归测试 | 80 项：79 通过，1 因当前 Windows 账户的原生符号链接权限跳过；Windows Junction 测试实际通过 |
| 记忆 | 17 项通过：范围、有效期、替代冲突、回退/删除、并发写、锁、损坏状态与进程间中文往返 |
| 反馈 | 15 项通过：明确采纳、范围、真实时间排序、记忆交接、删除、原子写及悬空 Junction |
| 设置 | 14 项通过：保存后跨进程复用、来源变化、绑定保持、过期计划拒绝、原子写及默认 Windows 目录 |
| 独立审查 | 已复现并修复范围空白归一化、跨时区排序和悬空 Junction；原始复现重新通过 |
| 记忆真实 CLI 集成 | 12 个独立 CLI 进程，6 项断言通过；反馈→候选→审核发布→后续读取，其他人、其他项目和未审候选被排除 |
| 独立业务任务 | 沿用记忆中的列顺序、千元单位与符号约定；对未见 CSV 得出 SYN-X 17.30、SYN-Y 2.10、合计 19.40 千元净流入 |
| 实际插件安装 | 当前客户端 CLI 成功导入 marketplace，安装 0.3.0；列表返回 installed=true、enabled=true |
| 新会话原生发现 | 独立的临时只读 CLI 会话从宿主技能目录发现 team-advisor-entry:team-advisor，读取安装缓存中的 SKILL.md 并确认 0.3.0 |
| 实际本机设置 | 三项技能来源及独立 Python 解释器已保存至本机 TeamAdvisor 专用目录；无业务连接或专业脚本执行 |
| Skill 与发布结构 | Skill Creator 格式检查通过；发布包必须通过 sources.json 指纹、路径、私有状态排除与 ZIP 完整性检查 |

回归总数包含 0.2.0 的 33 项，以及本版新增的 47 项。记忆范围由程序筛选，不是 OS 权限隔离。新会话验证针对当前客户端随附 CLI 的本地会话，不替代组织工作区与每位同事的安装验收。新会话日志中的既有 MCP 认证警告未阻止入口发现，也不能视为企业资料连接已经通过。

独立业务任务由没有开发上下文的代理执行，没有向它提供预期答案。金额从当前合成 CSV 计算，记忆中只有先前展示约定；DataLab 两份结果保留 checks_status=passed、status=needs_review，独立 Decimal 复算一致。输入未修改，结果不含图表。

## 仍需真实试点

公司资料源与权限、同事电脑、组织分发尚未验证。未自动收集聊天、发布团队记忆或创建定时整理任务。产品图表、模型及 Word 能力沿用此前逐任务待验范围；本版不以表格测试推断它们通过。

质量改善与节省时间尚未进行真实业务对照。已证明的是本地机制和合成任务可执行，不能由此宣称全团队质量提升。
