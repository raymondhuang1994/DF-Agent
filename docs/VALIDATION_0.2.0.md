## 能力报告的使用范围

报告使用 `ROOT_1` 等别名，包含本次来源公共文件指纹与运行时上下文。`execution_ready=true` 只针对所记录的具体任务、来源和环境。

df-mcp 的真实程序已在纯合成 local 来源完成索引、固定版本读取和导出，原文件哈希未变，`network_calls=false`。报告保留 `dependencies=unknown`、`execution_ready=null`，因为用户的公司资料源、身份及权限范围尚未确定；不会把合成测试推广为生产连接通过。

图表、模型、Word 的必要公共资源及包元数据已检测，业务烟雾测试保持 `not_checked`。完整能力尚需按需求逐项验收。来源或环境变化时，重新采集受影响证据，不能复制本报告作为另一台电脑的就绪证明。
